# Цветочный квартал

Браузерная игра: мердж цветов кормит тайкун цветочного магазина, который вырастает в квартал.

- Платформа: Yandex Games (HTML5), активные сессии 9–11 минут
- Жанр: merge + idle/tycoon
- Стек: TypeScript + Vite, рендер — DOM со спрайтами (лёгкий бандл, быстрый старт)

## Быстрый старт

```bash
tools/setup.sh   # поставить окружение (node_modules и tools/venv не сохраняются между сессиями)
npm run dev      # http://localhost:5173 — играбельная сборка
npm test         # 50 тестов: логика поля, экономика, интерфейс, звук
npm run build    # прод-сборка в dist/ (~3 МБ со спрайтами)
```

## Как играть (текущий билд)

- **Генераторы** внизу: клик тратит 1 энергии и ставит на поле предмет 1 уровня
- **Соединение**: клик по предмету, затем по такому же рядом. Три дают один предмет
  уровнем выше, пять — два
- **Заказы** справа: соберёшь нужные предметы — жми «Сдать», получишь монеты
- **Продажа**: клик по предмету → «Продать». Аварийный клапан, когда поле забито
- **Магазин** справа: апгрейды за монеты (холодильник, витрина, касса, склад, персонал, оранжерея)
- **Квартал** — кнопка в шапке: экран с шестью зданиями, которые открываются по дням
- **Звук** — кнопка в шапке. Синтезируется кодом, без звуковых файлов
- **Отладочная панель** в правом нижнем углу: монеты, энергия, промотка дней

## Структура

```
src/core/       логика без DOM: поле, слияние, заказы, экономика, сейв
  board.ts      поле и правила слияния (3→1, 5→2)
  game.ts       состояние игры и действия игрока
  orders.ts     генерация заказов, остывание вместо провала
  balance.ts    числа из data/balance.json
src/ui/         отрисовка: доска, заказы, магазин, квартал, звук
  quarter.ts    экран квартала: здания и мета-прогрессия
  audio.ts      звук на WebAudio: без файлов, глушится на время рекламы
src/data/       сгенерированные данные предметов (tools/gen-items.mjs)
art/manifest.json   спецификация арт-пакета (источник правды по цепочкам и названиям)
art/prompts.md      промпты всех ассетов с историей переделок
docs/handoff.md     передача работы другому разработчику или агенту
art/sprites/    60 спрайтов
data/balance.json   числа баланса — один файл на игру и на симулятор
tools/          инструменты: setup.sh, py, simulate.py, cutout.py, mock-board.py, next-batch.py, gen-items.mjs
```

- Мета: экран квартала с шестью зданиями
